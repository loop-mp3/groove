# Groove

## Groove is a lightweight lyrics API that resolves lyrics for YouTube tracks using YouTube metadata and LRCLIB.

## Features
* Resolves track metadata from YouTube and YouTube Music.
* Fetches plain and synced lyrics from LRCLIB.
* Falls back to title-only search when needed.
* Supports duration checks to avoid mismatched lyrics.
* Generates structured lyric files for [loop](https://loop.mizucode.qzz.io).

## Built for [loop](https://loop.mizucode.qzz.io)

* Groove powers lyrics resolution for [loop](https://loop.mizucode.qzz.io), helping it find and display lyrics with reliable fallbacks.
